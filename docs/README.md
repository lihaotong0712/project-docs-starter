# 文档

项目文档按以下五类组织。创建和维护文档见[写作与维护约定](authoring.md)，编写文档时，从所需分类的模板开始，并删除不适用的章节。

| 分类 | 用途 | 模板 |
| --- | --- | --- |
| [设计](design/README.md) | 项目目标、概念、架构、业务流程与实现机制 | [设计模板](design/TEMPLATE.md) |
| [规格](spec/README.md) | 功能或模块的行为规则、边界与验收场景 | [规格模板](spec/TEMPLATE.md) |
| [开发](development/README.md) | 一次工作的调研、原型、计划、任务与验证 | [开发模板](development/TEMPLATE.md) |
| [指南](guide/README.md) | 开发环境、调试、部署、回滚与故障处理 | [指南模板](guide/TEMPLATE.md) |
| [决策](adr/README.md) | 重要决策的背景、备选方案和取舍 | [决策模板](adr/TEMPLATE.md) |

分类内直接按主题建文件，内容增长后再按主题分目录。模板提供写作提示，项目主题文件按实际需要创建。
