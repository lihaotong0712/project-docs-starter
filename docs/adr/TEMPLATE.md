# 决策标题

使用 `0001-short-title.md` 命名，编号递增且不复用。仅记录需要独立追溯的重要选择，普通局部取舍保留在设计中。

## 背景与决定因素

说明需要决定的问题、目标、实际限制及决定时的已知事实，列出影响选择的关键因素与相关来源。

## 决策与确认依据

先写选择与适用范围，再说明采纳理由和可定位的实际确认依据。起草时使用 Draft，准备好后按需进入 InReview，确认后改为 Accepted。未采纳时按需使用 Rejected 并保留原因；未获确认时不得补写批准记录。

## 备选方案与取舍

简述实际考虑的重要备选，各自的收益、代价、风险及未采用原因。无需为了填模板虚构候选方案。

## 后果与验证

说明选择带来的正面和负面影响、需要采取的后续动作，以及如何检查预期效果。未来需要重新评估的触发条件有依据时再写；实际结果链接开发记录。

## 关联与替代

链接当前设计、规格或开发记录。采纳后保留原始背景与理由，普通事实补充可直接修正；改变选择时使用新决策，旧记录标记 Superseded，注明替代范围并互相链接。
